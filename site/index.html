Plugins y plantillas

Análisis que se suman a OpenKick. Cada plugin vive en el repositorio de su autor: entra, descarga el ZIP y cárgalo en OpenKick.

Ningún plugin coincide con la búsqueda.

Instalar un plugin

  1. Abre el repositorio del plugin.
  2. Pulsa Code › Download ZIP.
  3. En OpenKick: Plugins › Instalar plugin (.zip)… y elige ese archivo.

Publicar el tuyo

  1. Crea tu repositorio a partir de la plantilla de plugins.
  2. Escribe tu análisis en plugin.py, completa plugin.json y haz pasar sus tests.
  3. Propón añadirlo con un pull request que sume tu plugin a plugins.json. Se revisa antes de aparecer aquí.
OpenKick es software libre (GPLv3). Los plugins de la comunidad son de sus autores: revisa su código antes de usarlos con datos de pacientes.
